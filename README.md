# Ejercicios de Algoritmos en PSeInt

Este repositorio contiene una serie de ejercicios desarrollados en PSeInt para practicar conceptos fundamentales de lógica de programación, condicionales y operaciones aritméticas. Incluye también las representaciones gráficas de cada proceso mediante diagramas de flujo vectoriales (.svg).

---

## Descripción de los Algoritmos y Diagramas

| Archivo Fuente (.psc) | Diagrama de Flujo (.svg) | Descripción |
| --- | --- | --- |
| **`Saludo.psc`** | [Ver Diagrama](./diagramas/Saludo.svg) | Algoritmo de bienvenida sencillo que solicita el nombre del usuario e imprime un mensaje personalizado para Riwi. |
| **`EdadSoloEnDias.psc`** | [Ver Diagrama](./diagramas/EdadSoloEnDias.svg) | Solicita la edad en años y calcula el equivalente aproximado en días utilizando $365.25$ para contemplar los años bisiestos. |
| **`Notas.psc`** | [Ver Diagrama](./diagramas/Notas.svg) | Pide tres calificaciones (con validación de $0.0$ a $5.0$ mediante ciclos) y calcula el promedio final del estudiante. |
| **`Propinas.psc`** | [Ver Diagrama](./diagramas/Propinas.svg) | Calcula una cuenta de restaurante, aplica un porcentaje de propina y divide el total entre los comensales (con validaciones de datos mayores a cero). |
