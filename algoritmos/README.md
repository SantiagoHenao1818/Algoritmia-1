# Rueda Libre - Asistente de Taquilla

Este repositorio contiene los algoritmos y bitácoras desarrollados para automatizar las cotizaciones de alquiler de bicicletas, recorridos guiados y cálculo de cuentas grupales para **Rueda Libre**.

## Estructura del Repositorio

- `algoritmos/Minireto_2/01_cotizacion_basica.psc`: Algoritmo secuencial para cotizar el alquiler por horas de bicicletas individuales.
- `algoritmos/Minireto_3/02_cotizacion_recorrido.psc`: Cotización de recorridos guiados con cálculo de anticipo (30%) y saldo pendiente.
- `algoritmos/Minireto_4/03_cuenta_grupo.psc`: Asistente completo para consolidar la cuenta de un grupo, aplicar el 10% de aporte voluntario y dividir el total redondeando a la centena superior.
- `algoritmos/Minireto_4/Bitacora.md`: Documentación del análisis, descomposición de problemas y casos de prueba del MiniReto 4.

## Instrucciones para ejecutar en PSeInt

1. Descarga e instala **PSeInt**.
2. Configura el lenguaje seleccionando un perfil que exija la definición estricta de variables.
3. Abre PSeInt y ve a `Archivo > Abrir...`.
4. Selecciona cualquiera de los archivos `.psc` dentro de las carpetas de los miniretos y haz clic en **Ejecutar**.
